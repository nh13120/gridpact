GridPact HW9: what to do with each file

1. 1_Canvas_upload_GridPact_HW9_report.pdf  -> upload to Canvas (you AND Nicolas, same file).
   It has two placeholders "[paste the link to our slides ...]" (pages 1 and 5). Send the deck link and it gets regenerated:
   python coldstart/report/make_report.py --deck-url <link>
2. 2_slides_for_shared_deck.pptx            -> add these 4 slides to the shared Demo Day deck (keep them together).
3. 3_demo_video_upload_to_YouTube_Unlisted.mp4 -> upload to YouTube as Unlisted. Then on slide 2, Insert > Video > YouTube
   over the grey box, and set Format options > Video playback > Play (automatically).
